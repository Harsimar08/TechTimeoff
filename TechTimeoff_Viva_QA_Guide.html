1. Project Overview Questions

Q1: What is TechTimeoff and what problem does it solve?

Answer: TechTimeoff is a Leave Management System designed for educational institutions like JIMS. It solves the problem of manual leave application processes by providing a digital platform where:

  • Faculty can apply for leaves digitally
  • Coordinators can approve/reject them efficiently
  • Administrators can track leave balances and history
  • Real-time status updates eliminate paperwork
Benefits: Eliminates paperwork, provides real-time updates, improves efficiency, and maintains proper leave records.

5. Authentication & Security

Q10: How did you implement authentication in the frontend?

Answer: I implemented JWT-based authentication:

Login Process:

  1. User submits credentials
  2. API returns JWT token and user data
  3. Token stored in localStorage
  4. User state updated in Context
  5. Redirect to dashboard
Security Features:
  • Token validation - Check token validity on app load
  • Automatic logout - Clear invalid tokens
  • Route protection - Prevent unauthorized access
  • Token refresh - Refresh user data periodically
const login = async (userData, authToken) => { localStorage.setItem('token', authToken) setToken(authToken) setUser(userData) }

Q11: How do you handle API calls and error handling?

Answer: I created a centralized API utility (api-auth.js):

const API_URL = import.meta.env.VITE_API_URL || 'http://localhost:5000/api' export const authenticateUser = async (email, password, role) => { try { const response = await fetch(`${API_URL}/auth/login`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ email, password, role }) }) const data = await response.json() if (data.success) { return { token: data.token, user: data.user } } else { throw new Error(data.message) } } catch (error) { console.error('Authentication error:', error) throw error } }
Error Handling Features:
  • Try-catch blocks - Proper error catching
  • User feedback - Display error messages
  • Network errors - Handle connection issues
  • Token expiry - Automatic logout on invalid token
